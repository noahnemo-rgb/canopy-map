# Canopy

One mind-map for the repos you are building.

Levels: workspace, area, project, repo. One graph.
Add by path. Download or upload YAML. Gaps are notes you track. Canopy does not write the missing code.

Live preview of this build: https://raven-fire-rocket-acorn.grok.me/

Free: 1 map, 20 nodes. Pro is listed at $9/month and is not charged in this build.

This repo is the Canopy app only. It does not contain the ONE house mapper.

## Run

```
npm install
npm run dev
```

Sign-in secrets and the database URL are host environment variables. They are not in this repo.
